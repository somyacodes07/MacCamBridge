Security & First Launch

How to Open on macOS & Windows

Since MacCam Bridge is open-source and free, OS security prompts will appear on first launch. Here is how to bypass them in 5 seconds.

macOS Gatekeeper Bypass
Windows SmartScreen Bypass
1

Method A: Right-Click "Open" (Recommended)

In your Applications folder, Right-Click (or Control + Click) on MacCamBridge.app and click Open from the context menu.

On the dialog saying "Apple cannot check it for malicious software", click Open.

2

Method B: System Settings

Go to Apple Menu () → System Settings → Privacy & Security. Scroll down to the Security section, and click "Open Anyway" next to the blocked MacCamBridge notification.

3

Method C: Instant Terminal Command

Remove the quarantine flag with a single terminal command:

xattr -cr /Applications/MacCamBridge.app
1

Click "More info" on Blue SmartScreen Banner

When launching the installer or portable EXE, Windows SmartScreen will show a blue dialog saying "Windows protected your PC".

Click the underlined link labeled "More info".

2

Click "Run anyway"

A new button labeled "Run anyway" will appear in the bottom right corner. Click it to launch MacCam Bridge Receiver.

High-Performance Architecture

Engineered for Studio Quality

Built with native hardware acceleration pipelines on both macOS and Windows for lowest latency and zero dropped frames.

Sub-5ms Latency

Apple VideoToolbox zero-copy hardware encoding paired with Chromium WebCodecs GPU decoding eliminates audio/video desync.

USB-C Direct Link

Connect a USB-C to USB-C cable between Mac and PC. Uses high-bandwidth link-local IP (169.254.x.x) for zero Wi-Fi congestion.

Native System Webcam

Appears directly as "MacCam Bridge Camera" in Windows Device Manager. Compatible with Discord, Zoom, OBS Studio, and MS Teams.

Zero Config Bonjour

Automatically discovers Mac camera broadcasters across your local network without manual IP configuration.

Continuity Camera 4K

Supports iPhone Continuity Camera connected to your Mac, giving your Windows PC a 4K Sony-grade studio sensor.

100% Private & Local

Direct peer-to-peer streaming over TCP/WebSocket. No third-party servers, cloud relays, or internet traffic.
